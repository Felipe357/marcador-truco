# Marcador de Truco

Aplicativo simples de placar para partidas de truco, feito com Expo e React Native.

## Como executar

```bash
npm install
npm start
```

Leia o QR Code com o aplicativo Expo Go ou pressione `a` para abrir no Android.

## Funcionalidades

- Placar separado para Nós e Eles
- Controles para adicionar e remover pontos
- Botão progressivo para aumentar a mão: Truco (3), 6, 9 e 12 pontos
- Nomes personalizados para os times
- Nomes e total de vitórias salvos no armazenamento local do aparelho
- Contador persistente de partidas ganhas por time
- Vitória automática ao chegar a 12 pontos
- Reinício da partida com confirmação
